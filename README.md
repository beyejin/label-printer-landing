# 오지렌 미니 라벨프린터 랜딩페이지

폰, 카드, 케이블을 문구 한 줄로 꾸미는 라벨프린터의 수업용 A/B 랜딩페이지입니다. HTML, CSS, JavaScript만 사용하며 설치와 빌드 과정이 없습니다.

## 실행

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 다음 주소를 엽니다.

- A 소속감 버전: http://127.0.0.1:8765/?v=a
- B 취향 표현과 인정 버전: http://127.0.0.1:8765/?v=b
- A4 이미지용 화면: http://127.0.0.1:8765/?v=a&export=1

## 기능

- 같은 사진과 레이아웃에서 동기를 자극하는 문구가 다른 A/B 구성
- 데스크톱과 모바일 반응형 레이아웃
- 입력한 짧은 문구를 보여주는 라벨 미리보기
- 사용 예시와 꾸미는 순서 안내
- 실제 결제를 진행하지 않는 수업용 구매 버튼

## 파일

```text
index.html
styles.css
app.js
assets/
```

페이지의 제품 사진과 사용 예시는 AI로 생성한 연출 이미지입니다. 제품 사양, 가격, 후기와 판매 실적을 보증하지 않습니다. 상표와 제품명은 해당 권리자의 소유이며 이 페이지는 공식 판매 사이트가 아닙니다.

## 참고와 검증

[MUNBYN 제품 랜딩페이지](https://munbyn.com/pages/rw403b-bluetooth-thermal-label-printer)의 첫 화면 구성과 사용 예시로 이어지는 흐름을 참고했습니다. 다른 브랜드의 사양이나 판매 수치는 사용하지 않았습니다.

JavaScript 구문 검사, 이미지 로드, 입력 미리보기, 구매 버튼 안내, 데스크톱과 375px 모바일의 가로 넘침 여부를 확인했습니다. 결제, 분석 서버, 광고 추적 코드는 포함하지 않습니다.
